# 22. Generate Parentheses

**Difficulty:** Medium

## Topics

- String
- Dynamic Programming
- Backtracking
- Bracket Sequences

## Problem Statement

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses. 1 <= n <= 8

## Examples

- Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
- Input: n = 1
Output: ["()"]

## Constraints

- 1 <= n <= 8
